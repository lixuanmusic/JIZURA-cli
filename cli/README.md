# JIZURA 批量生成 CLI

每首歌 × 每个选中主题，各生成一个带音轨的 MP4。终端向导式交互，复用网页版引擎（无头 Chrome），不改动 app 本身。已在引擎 v0.10.1 上验证（24 个测试 + 真实数据端到端全通过）。

## 安装

```bash
cd JIZURA
python3 -m venv .venv
.venv/bin/pip install playwright questionary rich
.venv/bin/playwright install chromium   # 约 100MB，只需一次
```

## 使用

```bash
.venv/bin/python cli/jizura_batch.py
```

流程：输入文件/文件夹路径 → 自动识别配对（同名 `歌名.mp3` + `歌名.lrc`）→ 空格多选主题（文字PV / 动态文字 / 和风 / 恐怖 / 流行 / 抒情 / 不指定）→ 选画面比例、分辨率、FPS（默认 3:4 / 720p / 30fps）→ 确认摘要 → 逐条生成，进度条实时显示。

- 输入是单个文件时，只处理它所在的那一对。
- 输出到输入文件夹**同级**的 `output/`，命名 `主文件名_主题.mp4`。
- 同名文件已存在则跳过；加 `--force` 重新生成。
- 某条失败不影响其余，结束时汇总成功/失败清单。
- `Ctrl-C` 中断：已完成的结果保留。
- 每条生成参数（含随机种子）追加记录在 `output/jobs.json`。

## 歌词格式

- 支持逐行时间戳的 LRC（`[mm:ss.xx]` 前缀，毫秒精度可以）。
- 网易云导出的 JSON 元数据行（`{"t":…,"c":[…]}` 的作词/作曲行）会自动过滤。
- 无时间戳的行由引擎按时长估算位置；`/`（分卡）、`*强调*`、行尾 `!`、`[間奏 8]` 等引擎语法照常可用。

## 耗时参考（实测，约 3 分半的歌）

| 档位 | 每个视频 |
|---|---|
| 720p / 24fps | ~8 分钟 |
| 1080p / 24fps | ~5 分钟 |
| 1080p / 60fps | ~13 分钟 |

批量总数 = 歌数 × 主题数，注意累计时长与磁盘空间（1080p 每个约 40-80MB）。

## 常见问题

- **字体**：引擎从 Google Fonts 加载字体，需要联网；离线时自动回退系统字体（排版会有差异）。
- **声音**：MP4 内嵌 AAC 音轨；若浏览器编码器异常，详见网页版的说明。
- **测试**：`cd JIZURA && .venv/bin/python -m pytest cli/tests/`（含 `-m slow` 的引擎集成测试需 Playwright）。
