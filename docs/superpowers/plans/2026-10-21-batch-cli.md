# JIZURA 批量生成 CLI 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 终端向导批量调 JIZURA 引擎：每首歌 × 每个选中主题生成一个带音轨的 MP4。

**Architecture:** 新增 `cli/` Python 包，零改动引擎。本地 HTTP 服务同时伺服仓库根（index.html）与输入文件夹（/input/）；Playwright 无头页面内按 分析→主题随机→字体→plan→exportMP4 管线逐条生成，字节回传 Python 写盘。纯逻辑（配对、清洗、命名、日志）与浏览器驱动分离，前者 TDD。

**Tech Stack:** Python 3 + Playwright + questionary + rich；测试 pytest。

**Spec:** [docs/BATCH_CLI_DESIGN.md](../../BATCH_CLI_DESIGN.md)（含评审核实记录 [docs/BATCH_CLI_BUILDER_CHECK.md](../../BATCH_CLI_BUILDER_CHECK.md)）

## Global Constraints

- src/、index.html、app/ 零改动；只新增 `cli/`（spec：约束）。
- 目录不是 git 仓库：**无 commit 步骤**。
- 默认参数：3:4 / 720p / 30fps，向导中可改（spec：用户已定的决策 5）。
- `J.exportMP4` 的 `audio` 必须传 `J.analyzeAudio` 的**返回值**（传 File 会静默无声）；`J.omakase` 返回补丁须 `Object.assign` 回 project；导出前必须 `J.ensureFonts(歌词+title+artist+HUD_CHARS, J.fontsOfPlan(plan))`（spec：管线要点）。
- 引擎 API（已核实）：`J.analyzeAudio(File)→{name,duration,buffer,bpm,beats,energy,energyRate}`；`J.rng(seed)`；`J.omakase(project,rnd,themeId|null)`；`J.plan(project,audio)`；`J.defaultProject()`（字段 `themeId/title/artist/lyrics/aspect/res/fps/seed/quality/includeAudio`）；`J.exportMP4({plan,project,audio,quality,onProgress,signal})→{blob,codec,audio}`。
- 主题 key→中文名：`lyricpv`→文字PV、`kinetic`→动态文字、`wa`→和风、`horror`→恐怖、`pop`→流行、`ballad`→抒情；`None`→不指定（`themeId=null` 传给 omakase）。
- 输出：输入文件夹**同级**的 `output/`；写盘走 `.part` 临时文件，完成后 rename；同名跳过（`--force` 重跑）。
- Python ≥3.9；依赖 `playwright questionary rich`（chromium headless shell 已在本机 Playwright 缓存）。
- 测试数据（只读）：`/Users/lixuan/Code_local/music_data/data/raw`。

## Review Focus

1. **网易云 JSON 元数据行被渲染进视频** → `clean_lyrics` 过滤 `{` 开头行；测试断言（Task 2）。
2. **同名多音频选错/重复出片** → 优先级 mp3>m4a>wav>flac>ogg 去重；测试断言（Task 1）。
3. **损坏音频致整批崩** → 单条异常捕获记为失败、批次继续；测试断言（Task 6）。
4. **文件名含 `:` `/` 等字符写盘失败** → 输出文件名 sanitize（`/:` 替换 `_`）；测试断言（Task 3）。
5. **中断留下半截文件** → 只写 `.part`，成功才 rename；失败/中断删 `.part`；测试断言（Task 3）。
